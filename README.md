# Claude 업무 자동화 클래스

디자인 회사 대표님 대상 Claude 업무 자동화 과외 자료입니다.

| 폴더·파일 | 내용 |
|---|---|
| `docs/` | GitHub Pages 공유 사이트 (메인·강사 소개·교안 뷰어·다운로드) |
| `slides/` | 주제별 PPT 원본 (슬라이드 노트에 강사 메모 포함) |
| `커리큘럼.pdf` | 전체 과정 커리큘럼 (A4 1장) |
| `practice_materials/` | 실습용 가상 자료 |
| `lecture_draft.md` | 슬라이드 내용과 강사 메모 정리 |
| `영상_반영_내역.md` | 참고 영상 반영·미반영 내역 |
| `tools/` | PPT·커리큘럼 생성 스크립트 |

## GitHub Pages 배포

1. 저장소 **Settings → Pages**로 이동
2. **Source**: Deploy from a branch
3. **Branch**: 이 브랜치(또는 병합한 main) / 폴더 **`/docs`** 선택 후 Save
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열림

사이트의 PPTX 다운로드 파일에는 강사 메모(슬라이드 노트)가 빠져 있습니다. 메모가 있는 원본은 `slides/` 폴더에 있습니다.
